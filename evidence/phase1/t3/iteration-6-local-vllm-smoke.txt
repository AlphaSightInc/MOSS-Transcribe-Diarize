Verdict
PARTIAL, NON-GATING. The host has a real ARM64 vLLM 0.27.1 image that registers the MOSS
architecture, so iteration 3's engine-availability blocker is narrower than first measured.
No real decoder request or vLLM metric was obtained. The shared 8.2 GB Docker VM is not a safe
qualification environment while unrelated containers occupy it, and reconfiguring/restarting
Docker requires an operator-approved maintenance window. Do not infer a dispatcher bound from
this smoke result.
